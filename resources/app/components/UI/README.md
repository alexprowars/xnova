# UI kit

Общие компоненты нового дизайна. Импорт: `~/components/UI`.
Базовые стили полей и кнопок находятся в `styles/game/base.css`, стили остальных компонентов — в `styles/ui.css`. Цвета и общие размеры элементов управления задаются в `styles/variables.css`.

```vue
<template>
	<UiHeading :title="$t('pages.notes.index.title')" :count="items.length">
		<template #actions>
			<UiButton :as="Link" href="/notes/create">Создать заметку</UiButton>
		</template>
	</UiHeading>
	<UiPanel clip title="Заметки">
		<UiEmptyState v-if="!items.length">Заметок пока нет</UiEmptyState>
		<UiTable v-else>
			<thead><tr><th scope="col">Название</th></tr></thead>
			<tbody><tr v-for="item in items" :key="item.id"><td>{{ item.title }}</td></tr></tbody>
		</UiTable>
	</UiPanel>
</template>

<script setup>
	import { Link } from '@inertiajs/vue3';
	import { UiButton, UiEmptyState, UiHeading, UiPanel, UiTable } from '~/components/UI';

	defineProps({
		items: Array,
	});
</script>
```

| Компонент | Использование |
| --- | --- |
| `UiHeading` | `title`, необязательный `count` (включая 0); слоты `title` и `actions`. Слот по умолчанию заменяет всё содержимое для сложных заголовков. |
| `UiPanel` | `title`, `as` (по умолчанию `section`), `clip` для обрезки содержимого по границам. Слот `header` заменяет заголовок; основной слот содержит тело без дополнительной обёртки. |
| `UiButton` | `variant`: `primary`, `secondary`, `danger`, `success`; `icon` для квадратной кнопки. По умолчанию настоящий `button` с `type="button"`; для отправки формы явно указывать `type="submit"`. |
| `UiCount` | Компактный счётчик, содержимое передаётся через слот. |
| `UiEmptyState` | Пустое состояние со слотом для текста и действий. Отступ можно уточнить переменной `--ui-empty-padding`. |
| `UiBackLink` | Inertia-ссылка с общей иконкой «назад»; обязательный `href`, текст через слот. |
| `UiTable` | Нативная таблица с общим оформлением. `thead`, `tbody` и строки передаются через слот. |
| `UiTabs` | Вкладки с панелями: `items` (`id`, `label`, необязательный `disabled`), `label` для доступного названия списка, необязательный `v-model` выбранного `id`. |
| `UiTabNavigation` | Вкладки-ссылки: `items` (`id`, `label`, `href`, необязательный `count`), `active`, `label`. `embedded` убирает внешнюю рамку для размещения внутри панели. |
| `UiTabSelect` | Переключатель значения с оформлением табов и семантикой группы радиокнопок: обязательный `v-model`, `items` (`id`, `label`, необязательные `disabled` и `color`), `label`. Подходит для выбора категории графика. |

`UiButton` принимает `as="a"`, `:as="Link"`, `:as="ModalLink"` или компонент ссылки. Атрибуты (`href`, `disabled`, `aria-label`, `navigate`) и события передаются корневому элементу. Для отключаемого действия используйте нативную кнопку: у HTML-ссылки нет состояния `disabled`. Кнопке только с иконкой нужен `aria-label`.

Нативные `input`, `select` и `textarea` получают общее оформление автоматически, включая состояния `hover`, `focus-visible`, `disabled` и ошибки (`error`, `is-invalid` или `aria-invalid="true"`). Для обычной кнопки или ссылки используется класс `button`; варианты — `is-secondary`, `is-danger`, `is-success`, компактная кнопка с иконкой — `icon-button`. `UiButton` использует эти же базовые правила. В стилях страниц задаются только особенности раскладки и необходимые размеры.

Для простых обёрток доступны классы `ui-form-body` (отступы формы), `ui-actions` (ряд действий), `ui-errors` (сообщения валидации). Существующие `game-*` стили форм, текста и компактных таблиц также находятся в `styles/ui.css`.

Ширины столбцов, мобильная раскладка таблиц и предметные состояния остаются в стилях страницы. Существующие классы на компонентах сохранены там, где нужны локальные уточнения. При добавлении страницы используйте компоненты и добавляйте только её особенности, без копирования базовых стилей.

## Блоки

Для существующей разметки `block` общие рамка, фон, скругление, заголовок `title` и содержимое `content` заданы в `styles/game/base.css`. Размеры задаются переменными `--ui-block-*` в `styles/variables.css`. Содержимое по умолчанию без отступов для таблиц; класс `content is-padded` добавляет единый внутренний отступ. На страницах остаются раскладка содержимого и внешние отступы, обусловленные соседними элементами.

## Вкладки

```vue
<UiTabs :items="[
	{ id: 'general', label: 'Основное' },
	{ id: 'description', label: 'Описание' },
]" label="Настройки">
	<template #general>Основные настройки</template>
	<template #description>Описание профиля</template>
</UiTabs>
```

Имена слотов соответствуют `id`. Для вкладок с одинаковой структурой используйте общий слот `#panel="{ item }"`, например в списке технологий. Значения `id` должны быть уникальными и стабильными; они не зависят от перевода подписи. Первая доступная вкладка выбирается автоматически, в том числе после удаления или отключения выбранной вкладки.

По умолчанию содержимое скрытых панелей остаётся смонтированным: введённые значения и поля общей формы сохраняются. `unmount-on-hide` используйте для тяжёлого содержимого, состояние которого хранится в родителе, как в империи. `UiTabs` и `UiTabSelect` используют уже установленный `reka-ui` для переключения с клавиатуры и управления фокусом. `UiTabNavigation` сохраняет обычные Inertia-ссылки, открытие в новой вкладке и `aria-current="page"`.

Все три компонента используют общие `.ui-tab-list` и `.ui-tab-trigger` в `styles/ui.css`, включая активное состояние, фокус и мобильные отступы. Страничные варианты оформления табов добавлять не нужно.
